# 何发 · He Fa

艺术家、电影创作者，P4剧场共同发起人与长期主理人。创作涉及摄影、影像装置、剧场、电影与写作。

Artist and filmmaker working across photography, moving-image installation, theatre, film and writing. Co-initiator and long-term organiser of P4 Theater. Earlier English records also use the name **Fa He**.

[何发个人网站](https://hefa.p4theater.cn/) · [English](https://hefa.p4theater.cn/en) · [P4剧场](https://p4theater.cn/) · [P4经典版](https://p.p4theater.cn/) · [P4归档目录](https://github.com/hehefa/-p4-theater-archive/blob/main/INDEX.md)

## 从作品进入 · Works

**《人类投降派》 / Shoot Self with You · 2023–2024**  
从招募、排练与公开演出中生长出的实验电影。何发担任导演、发起、制片与剪辑；全剧组共同创作。

Directed, initiated, produced and edited by He Fa; collectively created with the full crew.

[电影与完整署名](https://hefa.p4theater.cn/work/human-surrender) · [P4电影页](https://p4theater.cn/shoot-self-with-you/)

**《膜下》 / Under the Membrane**  
沿现场、图像与片段进入《人类投降派》的互动数字作品。

[进入作品](https://s.p4theater.cn/) · [项目仓库](https://github.com/hehefa/p4-submembrane-cn)

摄影、装置与其他作品见[个人网站作品目录](https://hefa.p4theater.cn/archive)，P4的项目与原始记录见[P4公共档案](https://a.p4theater.cn/)。

## P4剧场 · P4 Theater

P4始于北京，以表演、摄影、影像和写作创造现场，并保存其中发生的关系与记录。何发与张绍华于2015年前后共同发起P4剧场，此后何发持续主理并组织创作。
